SafePoint remains only an asynchronous drain. After its last await, one detached/deep-frozen R* synchronously proves:

- exact source object, session ID, Runner ID, ACTIVE lifecycle epoch and zero history;
- idle, no stream, no queued message, no retry and no compaction;
- exact protected failed handoff/failure digest and ACTIVE binding including incarnation;
- exact current plan task/revision/byte digest/full canonical semantics and position;
- actual model/reasoning and current Git identity;
- freshly verified checkpoint and manifest bytes, content digests and protected relationship;
- exact protected latch state/generation/reason with no takeover;
- no protected resume readiness, authorization, admission or dispatch evidence.

The short final PlanRevisionWriter coordination contains R* capture and the synchronous protected transaction. It contains no await, UI, model/provider/network callback or caller-supplied hook. Artifact verification returns the same detached bytes used by semantic verification; paths are not reopened after acceptance.

The protected transaction revalidates every protected member of R*, inserts the decision, supersedes the exact binding and lifecycle event, appends `CONTINUITY_RECOVERY_STARTED`, reserves the exact child/plan/active-source/event and records the request result before one COMMIT. Any failure rolls back all of them.

## Ordering and crash interpretation

- takeover first: no decision, supersession, recovery event or child;
- recovery transaction first: exact recovery decision/child survives; later takeover blocks future progress under existing latch semantics;
- simultaneous: SQLite chooses one of those serial orders;
- shutdown/supersession first: stale binding/incarnation rejects;
- unrelated shutdown: no protected subject movement;
- pre-COMMIT crashes after decision, binding, event, child or immediately before COMMIT: complete rollback;
- COMMIT before compatibility projection: complete canonical recovery survives and projection is independently repairable.
